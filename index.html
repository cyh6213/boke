Quick Answers

常问问题

01实习安排

到岗时间：拿到 Offer 后五天内可以到岗。

实习时长：没有时间限制，可以长期实习；每周可以到岗五天。

实习地点：没有 Base 要求。相对倾向成都，但其他城市也可以。

课程安排：学校的专业课主要集中在大二，大三上专业课较少，大三下统一没有课，主要用于实习。因此，我只需要在大三上期末回学校参加考试，不会影响实习。

02为什么上一份实习时间较短？

首先，为什么选择加入。这是我的第一份正式实习，也是进入字节了解真实业务环境的机会。虽然入职前我知道这个岗位更偏 AI Agent 应用，而不是底层开发，但我仍然认为它值得尝试。

一方面，我希望了解大厂真实的协作流程，以及 AI 在生产业务中到底如何落地；另一方面，我之前做 Agent 项目时，很多需求判断来自自己的想象，而这段实习让我能够接触真实业务和实际约束，知道企业真正关注的是什么。

其次，为什么决定离开。实际工作一个多月后，我发现岗位的长期核心仍然是通过 Skill 和现有 Agent 平台完成运营提效，并围绕机审效果等业务指标持续优化。我认可这些工作的价值，也确实学到了 Agent 应用和业务落地经验，但它和我的长期方向存在比较明确的差异。

我的职业方向是 Agent 工程开发，希望深入参与代码实现、Agent 策略和工程稳定性建设，而不只是使用既有平台完成业务任务。因此，在确认这种差异是岗位长期属性，而不是暂时安排之后，我决定尽早调整方向。

这次离开并不是因为工作强度、团队氛围或者短期困难，也不是频繁尝试不同岗位。它让我更清楚地验证了自己的职业方向。下一份实习我会在加入前重点确认岗位职责和长期工作内容。如果岗位确实以 Agent 开发为主，我希望能够长期投入，并持续做出完整成果。

03在 Agent 开发方向，你了解什么，不了解什么？

RAG：我做过完整的 RAG 项目，对 RAG 的基础流程、检索优化和测评方法比较了解。

Agent 工程：我的核心项目是一个多 Agent 编排系统，因此我对多 Agent 交互、长链路任务的难点、上下文组织、Skill 设计和 Prompt 调优比较了解。项目中也设计了 Trace 可观测性、异常处理和 Agent 测评，并实践了 Harness Engineering、Loop Engineering 和 Graph Engineering。此外，我还做过人机交互、Token 用量和 Tool 按需加载等方面的优化。

目前的能力边界：我没有做过模型微调相关工作；目前最熟悉的开发语言是 Java，其他语言的工程经验相对不足。如果岗位需要，我可以补充学习并转换语言。
